# BMS / BME / BML Importer for REAPER

BMS (`.bms`, `.bme`, `.bml`) ファイルの音符・テンポデータを解析し、REAPER上にStem（マルチトラック）オーディオおよびテンポマップを自動構成する ReaScript (Lua) です。

---

## 主な機能

- **高精度タイムライン同期**
  - BPM変更 (`#BPM`, `#03`, `#08`)、STOP命令 (`#STOP`, `#09`)、小節長変更 (`#02`) を厳密に計算し、音声アイテムを絶対時間軸上で正確に配置します。
- **変拍子（小節長変更）完全対応**
  - $3/4$ 拍子や $5/4$ 拍子、小節長の任意倍率変更（`#02`）が混在する楽曲においても、再生タイミングの発音ズレを発生させずに正確に同期します。
- **自動ステム・フォルダ構造化**
  - 音声定義（`#WAV`）のファイル名接頭辞を解析し、カテゴリごとにグループ化されたフォルダートラック（`BMS Stems` / `Grp: xxx`）を自動構築します。
- **柔軟なオーディオファイル検索**
  - `.wav`, `.ogg`, `.flac`, `.mp3`, `.aac` などの拡張子違いや、大文字・小文字の表記表記差を自動的に補正して検出します。
- **同一トラック上の重ね押し自動カット**
  - 同一トラックで発音命令が連続する場合、前の音声アイテムの長さを自動的に次発音位置まで短縮し、重複再生による不自然な重なりを防止します。
- **依存関係フリー**
  - REAPER標準の Lua API のみで動作します。SWS Extension が未インストールの環境でもエラーで停止することはありません（インストール済みの場合はプロジェクト Timebase の自動最適化を行います）。

---

## 変拍子（#02 チャンネル）の処理仕様

BMS形式における `#xxx02:val`（小節長倍率指定）に対する本スクリプトの計算ロジックは以下の通りです。

1. **累積拍数とタイムラインの動的計算**
   - 各小節 $m$ の倍率 $m_{\text{len}}$ を基に、各小節の開始拍数を `current_beat = current_beat + (m_len * 4.0)` として動的に計算します。
   - 小節途中に配置されたオブジェクトの絶対拍位置 $B$ は、小節内位置 $P \in [0, 1)$ を用いて $B = \text{start\_beat}[m] + (P \cdot m_{\text{len}} \cdot 4.0)$ で算出されます。
2. **絶対時間軸への変換**
   - 算出された拍位置とテンポ変更・STOPイベントを組み合わせて絶対時間（秒）へ変換するため、REAPERのグリッド設定や拍子記号の有無に依存せず、音声波形の位置精度が保たれます。

## 動作要件

- **REAPER**: v6.0 以降推奨
- **依存ライブラリ**: なし
  - *(任意)* **SWS Extension**: 導入環境ではプロジェクトの Timebase 設定を自動で `Time` に統一し、波形の不意な伸縮を防止します。

## インストール手順

### 手動インストール

1. REAPER を起動します。
2. メニューから **[Actions]** $\rightarrow$ **[Show action list...]** を開きます（ショートカット: `?`）。
3. ウィンドウ右下の `New action...` $\rightarrow$ `New script...` をクリックします。
4. 作成するファイル名（例: `BMStoRPP.lua`）を入力して保存します。
5. 開いたスクリプトエディタに `BMStoRPP.lua` のコードを貼り付け、保存（`Ctrl+S` / `Cmd+S`）してエディタを閉じます。

---

## 使い方

1. REAPER で新規プロジェクト（または編集中のプロジェクト）を開きます。
2. **Action List** を開き、追加した `BMStoRPP.lua` を選択して **[Run]** を実行します。
3. ファイル選択ダイアログが表示されるため、読み込む `.bms`, `.bme`, `.bml` ファイルを選択します。
4. 解析が完了すると、トラック構造およびテンポマップが自動生成されます。

## トラブルシューティング

- **音声ファイルが読み込まれない（Missing files）**
  - BMSファイルが存在するディレクトリまたはその相対パス配下に、指定された音声ファイル（`.wav`, `.ogg` 等）が存在するか確認してください。
- **再生途中でテンポや音声の位置がずれる**
  - REAPERのプロジェクト設定（`Alt + Enter`）を開き、**Project timebase for items/envelopes/markers** が `Time` に設定されているか確認してください。
